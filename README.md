## Website

Real Finance Decoded is a static research blog. The white and blue design pairs one featured essay with a simple collection of research chapters and a clean reading layout.

- `index.html` contains the research and page structure.
- `styles.css` contains the theme, responsive layouts, and print styles.
- `site.js` handles the existing chapter links and the mobile menu.
- `assets/` contains the original illustrations and self-hosted fonts, with their licenses.

No installation or build step is required. To preview locally:

```sh
python -m http.server 4173
```

Open `http://localhost:4173`. Deploy the repository root as a static website, including `assets/`, `styles.css`, and `site.js`.

Existing chapter links such as `#problem`, `#technical`, and `#resources` continue to work. All research remains available when JavaScript is disabled. The seven original research bodies and their source links are preserved.

The blue REAL Finance logo is used for site branding, PNG favicons, the Apple touch icon, and the Open Graph / X share image. The logo assets are the matching official files from real.finance. X uses a square summary card to keep the complete logo visible.
